# WebSocket 空闲连接阶梯报告

## 1. 测试日期

2026-11-08

## 2. 测试目标

逐级验证单实例 GinChat 在 100、500、1,000 个空闲 WebSocket 连接下的：

- 一次性 Ticket 建连成功率。
- WebSocket 握手延迟。
- 20 秒连接稳定性。
- 服务端连接数、Goroutine 和堆内存。
- 连接关闭后的资源回收。

## 3. 测试环境

| 项目 | 配置 |
| --- | --- |
| CPU | AMD Ryzen 7 5800H，8 核 16 线程 |
| 内存 | 32 GB |
| 操作系统 | Windows 11 家庭版，10.0.26200 |
| Go 服务 | Windows 本机直接运行 |
| Redis | Docker Desktop WSL2，Redis 7.4 |
| 压测工具 | Docker 容器 `grafana/k6:0.57.0` |

其他业务基础设施保持运行，但本场景只建立 WebSocket 连接，不发送聊天消息。

## 4. 测试方法

- 服务限制每个用户最多 10 个连接。
- 100、500、1,000 个连接分别使用 10、50、100 个独立用户。
- 每个 VU 只执行一次：登录、申请 Ticket、建立连接、保持 20 秒、主动关闭。
- 每个 VU 随机等待 0 至 5 秒后建连，避免完全同一时刻形成极端尖峰。
- k6 自动完成 WebSocket Ping/Pong 协议处理。
- 测试期间每秒请求一次 `/metrics`，记录服务端连接、Goroutine 和堆内存峰值。

## 5. 结果汇总

| 连接数 | 建连成功 | 握手 P95 | 握手 P99 | 最大握手 | 服务端连接峰值 | Goroutine 峰值 | 堆内存峰值 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 100 / 100 | 11.17 ms | 17.54 ms | 23.56 ms | 100 | 未完整采样 | 未完整采样 |
| 500 | 500 / 500 | 4.81 ms | 8.56 ms | 21.35 ms | 500 | 1,543 | 28.1 MiB |
| 1,000 | 1,000 / 1,000 | 21.83 ms | 52.91 ms | 75.07 ms | 1,000 | 3,043 | 45.6 MiB |

共同结果：

- 建连成功率均为 100%。
- 20 秒保持期间未记录异常关闭。
- 连接成功关闭后，服务端 `ginchat_websocket_connections` 回到 0。
- 所有连接均满足每用户最多 10 连接的现有约束。

## 6. 观察

### 6.1 连接建立

1,000 连接时握手 P95 从 500 连接时的约 4.8 ms 上升到 21.8 ms，但 P95 仍远低于 1 秒阈值。该变化主要发生在大量 VU 同时建立连接时，反映客户端、Windows 网络栈和 Go 服务共同承受瞬时压力。

### 6.2 Goroutine

500 连接时 Goroutine 峰值约 1,543，1,000 连接约 3,043。增量与连接数近似线性，约等于每个连接增加约 3 个 Goroutine，符合当前连接读协程、写协程和运行时代码路径的预期。

### 6.3 内存

500 连接时堆内存采样峰值约 28.1 MiB，1,000 连接约 45.6 MiB。该数据包含 k6 发起的连接、Redis 心跳、JWT Ticket 验证和 GC 时序影响，不能直接当成单连接固定内存成本。

### 6.4 资源回收

测试结束后连接数回到 0。服务端随后 Goroutine 回落到约 41，说明正常关闭路径可以释放连接相关协程。

## 7. 与目标的关系

需求目标是 5,000 个空闲 WebSocket 连接。本次已验证到 1,000 个连接，不能直接宣称已经支持 5,000 连接。

下一步应继续执行 2,000 和 5,000 连接阶梯，同时记录：

- Windows 文件描述符和端口占用。
- Go 进程 RSS，而不只是堆内存。
- CPU、GC 暂停和调度延迟。
- 客户端 k6 自身资源占用，避免压测机先成为瓶颈。
- 连接稳定保持 5 至 10 分钟后的 Ping/Pong 和资源变化。

## 8. 已知限制

- 连接仅保持 20 秒，短于服务端 25 秒 Ping 周期。
- 未覆盖网络抖动、丢包和断线重连。
- k6 客户端与服务端运行在同一台电脑。
- 未发送业务消息，不包含群扇出和回执写入。
- 暂未采集 RSS 和文件描述符。
