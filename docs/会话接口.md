# 会话接口

所有接口都要求 `Authorization: Bearer <JWT>`，当前用户只能从认证上下文读取，不能由请求体伪造。

## 1. 创建或获取私聊

```http
POST /api/v1/conversations/private
Content-Type: application/json
```

```json
{
  "peer_user_id": "1839281749283749120"
}
```

- 首次创建返回 `201 Created`。
- 相同两个用户再次请求时返回已有会话和 `200 OK`。
- 私聊由较小的用户 ID 和较大的用户 ID 唯一确定，数据库唯一索引负责处理并发创建。
- 不能与自己创建私聊；用户不存在时返回 `404 Not Found`。

## 2. 创建群聊

```http
POST /api/v1/conversations/groups
Content-Type: application/json
```

```json
{
  "name": "后端学习群",
  "avatar_url": ""
}
```

- 群名称去除首尾空格后不能为空，最多 64 个 Unicode 字符。
- 创建会话和加入群主成员在同一事务中完成。
- 成功返回 `201 Created`。

## 3. 我的会话列表

```http
GET /api/v1/conversations
```

```json
{
  "conversations": [
    {
      "id": "1839281749283749120",
      "conversation_type": 1,
      "name": "",
      "avatar_url": "",
      "last_seq": 5,
      "last_read_seq": 2,
      "unread_count": 3
    }
  ]
}
```

当前只返回有效成员关系中的正常会话，按会话最近更新时间倒序，首版限制 100 条。未读数由 `last_seq - last_read_seq` 计算，结果不会是负数。

## 4. 代码边界

| 文件 | 职责 |
| --- | --- |
| `internal/conversation/handler.go` | HTTP 参数转换和错误映射 |
| `internal/conversation/service.go` | 输入规则、状态语义和未读数计算 |
| `internal/conversation/repository.go` | 会话事务、唯一冲突恢复和列表查询 |
| `internal/router/conversation/conversation_router.go` | 路由组装和统一认证中间件 |

接口不使用旧版 `groups` 和 `messages` 表，新链路以 `conversations`、`conversation_members` 和后续的 `messages` 为事实来源。
