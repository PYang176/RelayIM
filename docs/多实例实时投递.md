# 多实例实时投递

RelayIM 的实时消息不依赖单个 Go 进程。多个应用实例共享 MySQL、Redis 和 RabbitMQ，通过 Redis 查询设备所在实例，再由 RabbitMQ 定向投递。

## 1. 实例定义

一个实例是一份运行中的 Go 程序进程或容器。实例 ID 由主机名、PID 和进程启动时间组成，避免 PID 复用导致临时队列和旧路由混用。

每个实例必须配置不同且有效的 Snowflake Worker ID：

```text
RELAYIM_SNOWFLAKE_WORK_ID=1
RELAYIM_SNOWFLAKE_WORK_ID=2
```

## 2. Redis 设备路由

WebSocket 建连和 Pong 时写入：

```text
relayim:ws:route:user:<user_id>
```

ZSET Member 格式：

```text
<instance_id>|<device_id>
```

路由 TTL 为 70 秒。查询时原子清理旧设备，并按实例去重。连接正常关闭会删除当前设备 Member，不影响同一用户的其他设备。

注册实时路由失败时 WebSocket 建连会关闭并让客户端重试，避免出现“在线但无法实时接收”的假状态。

## 3. 领域事件路由

领域事件由单个共享 `im.events.fanout.v2` 竞争消费。消费者完成 MySQL 幂等和事实校验后：

1. 消息事件查询会话全部有效成员，群邀请事件选择被邀请人。
2. 从 Redis 得到目标用户所在的实例。
3. 按实例聚合用户 ID。
4. 向 `im.delivery` Direct Exchange 发布节点投递命令。

每个实例启动时声明：

```text
im.delivery.node.<instance_id>
```

该队列是 Exclusive、Auto-delete、非持久化队列。目标实例消费后只向本进程的 WebSocket Manager 投递。

## 4. 投递语义

- 业务事实以 MySQL 为准。
- RabbitMQ 领域事件保持至少一次投递，`processed_events` 防止同一消费者重复执行。
- 节点投递命令可能因事务重试重复发布，客户端按 `message_id` 去重。
- 消息创建事件会发送给会话全部有效成员，包括发送者账号的其他设备。客户端应识别自己的消息，避免重复显示。
- 实例退出或节点队列暂时不可路由时，实时帧允许丢失；聊天重连后先请求最新页，群邀请通过 HTTP 邀请列表恢复。
- 客户端维护连续 `seq` 水位；检测到缺口时立即补拉，且不会越过缺口推进已读位置。
- 不宣称 Exactly Once，也不依赖 WebSocket/RabbitMQ 帧顺序，业务顺序始终以会话内 `seq` 为准。
- 领域事件和节点投递命令通过 RabbitMQ Header 传播 W3C `traceparent`，跨实例链路可在 Tempo 中使用同一个 `trace_id` 查询。

## 5. 拓扑

```text
MySQL 事务
  -> Outbox
  -> im.events
  -> im.events.fanout.v2（所有实例竞争消费）
  -> Redis 查询用户实例
  -> im.delivery
  -> im.delivery.node.<instance_id>
  -> 本实例 WebSocket 有界队列
```

## 6. 验证

先准备演示数据并启动两个实例：

```powershell
.\scripts\seed-demo.ps1
.\scripts\run-server.ps1 `
    -ServerAddr "127.0.0.1:18081" `
    -SnowflakeWorkID 1
```

第二个终端启动：

```powershell
.\scripts\run-server.ps1 `
    -ServerAddr "127.0.0.1:18082" `
    -SnowflakeWorkID 2
```

然后执行：

```powershell
node scripts/two-instance-e2e.mjs
```

脚本验证：

- Alice 设备 1 连接实例 1。
- Alice 设备 2 和 Bob 连接实例 2。
- Alice 在实例 1 发送私聊消息。
- 三个连接都收到消息事件。
- 撤回事件同样到达三个连接。

群邀请实时通知可执行：

```powershell
python scripts\group-invitation-e2e.py
```

在线被邀请人无需等待 30 秒轮询即可收到邀请；取消邀请同样会实时移除待审批项。
