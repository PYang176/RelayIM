# RelayIM 开发依赖与工具

本文档归档项目需要的本地开发工具和主要 Go 依赖。依赖版本以 `go.mod` 和
`web/package-lock.json` 为准，不在业务文档中重复维护完整版本清单。

## 1. 基础工具

| 工具 | 用途 |
| --- | --- |
| Go 1.26.11 | 编译和测试后端 |
| Node.js 24、npm | 构建和测试 Vue 前端 |
| Docker Desktop | 运行 MySQL 之外的基础设施 |
| Goose v3.24.3 | 执行 MySQL migration |
| MinGW-w64 | 在 Windows 上支持 `go test -race` |

项目在 `go.mod` 的 `go` 指令中声明 Go `1.26.11`，由 `GOTOOLCHAIN=auto` 自动选择该安全版本。Windows 用户级环境应保持：

```powershell
[Environment]::SetEnvironmentVariable(
    "GOTOOLCHAIN",
    "auto",
    "User"
)
```

修改后需要重新打开终端。检查实际工具链：

```powershell
go env GOVERSION
```

检查版本：

```powershell
go version
node --version
npm --version
goose --version
gcc --version
docker version
```

## 2. Go 依赖类别

| 类别 | 主要依赖 |
| --- | --- |
| HTTP 与配置 | Gin、Viper、YAML |
| 数据库 | GORM、MySQL Driver |
| 认证与安全 | JWT v5、bcrypt |
| 实时通信 | Gorilla WebSocket |
| 消息队列 | amqp091-go |
| 缓存与限流 | go-redis |
| 对象存储 | MinIO Go SDK |
| 标识生成 | Snowflake |
| 可观测性 | Prometheus Client、OpenTelemetry |

恢复完整依赖：

```powershell
go mod download
go mod verify
```

修改依赖后执行：

```powershell
go mod tidy
go run golang.org/x/vuln/cmd/govulncheck@v1.9.0 ./...
go vet ./...
go test ./...
go test -race ./...
```

## 3. 常用依赖安装方式

依赖主要由 `go mod tidy` 管理。需要显式添加模块时使用：

```powershell
go get github.com/gin-gonic/gin
go get github.com/spf13/viper
go get gorm.io/gorm
go get gorm.io/driver/mysql
go get github.com/golang-jwt/jwt/v5
go get github.com/gorilla/websocket
go get github.com/redis/go-redis/v9
go get github.com/rabbitmq/amqp091-go
go get github.com/minio/minio-go/v7@v7.0.95
go get github.com/prometheus/client_golang@v1.23.2
```

不要直接升级全部依赖。先确认 Go 版本兼容性，再运行完整测试。

## 4. OpenAPI 生成

接口契约以 `docs/openapi.yaml` 为事实来源，修改后生成同步 JSON：

```powershell
go run ./scripts/openapi
```

## 5. 前端依赖

```powershell
Set-Location web
npm ci
npm audit --audit-level=high
npm run typecheck
npm run test:unit
npm run build
```

`package.json` 管理直接依赖，`package-lock.json` 锁定可复现安装版本。

## 6. 安全基线

- Go 工具链不得低于 `go.mod` 声明的版本
- `govulncheck` 必须报告代码可达漏洞为零
- `npm audit --audit-level=high` 必须通过
- Dependabot 每周检查 Go、npm 和 GitHub Actions 依赖
- 发现可达漏洞时先升级或移除受影响路径，不能只通过忽略规则消除告警
